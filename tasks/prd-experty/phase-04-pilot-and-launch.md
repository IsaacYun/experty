# Phase 4: 파일럿·유료 출시

Parent PRD: [PRD: Experty](../prd-experty.md)
Status: Not Started
Last Updated: 2026-08-08

## Objective

전문가 5명 파일럿으로 제품 가설을 검증하고 유료 공개 출시를 준비한다.

## Context From Master PRD

- Goals Covered: G-1, G-2, G-3, G-4
- Success Criteria: SC-1, SC-2, SC-3, SC-4
- Requirements Covered: 전체 MVP 요구사항

## Phase Discovery Gate

- [ ] 5명 파일럿 대상, 온보딩 담당자, 개인정보 동의, 기존 문의 채널을 확인한다.
- [ ] 유료 결제 계약과 고객 지원 채널을 확인한다.
- [ ] 개인정보처리방침, 이용약관, 구독·환불 정책의 검토 완료 여부를 확인한다.
- [ ] 장애 대응자와 백업·복구 절차를 확인한다.

## Scope

### In Scope

- [ ] 파일럿 전문가별 프로필·활동·문의 링크를 세팅한다.
- [ ] 8주간 Pro 권한을 부여하고 주간 사용성 인터뷰를 진행한다.
- [ ] 문의 수, 응답 시간, 확정률, 알림 실패, 캘린더 오류를 계측한다.
- [ ] 파일럿 결과에 따라 문의 필드·상태·알림을 개선한다.
- [ ] 결제·약관·지원 문서·운영 대시보드를 갖춰 유료 출시한다.
- [ ] 후속 사람 매니지먼트 서비스의 수요와 운영 비용을 별도 조사한다.

### Out of Scope

- 매니지먼트 대행의 실제 계약·가격 책정·인력 채용.

## Validation Strategy

- 실제 전문가 링크에서 문의 접수부터 수락·일정 생성까지 운영 테스트한다.
- 주간 KPI와 고객 인터뷰로 정성·정량 검증한다.
- 유료 출시 전 보안, 권한, 결제, 백업, 개인정보 삭제를 운영 점검한다.

## Exit Criteria

- [ ] 마스터 PRD의 모든 성공 기준을 측정해 기록한다.
- [ ] 유료 전환 결과와 유지·수정·중단 결정을 문서화한다.
- [ ] SaaS와 후속 매니지먼트 서비스의 경계와 다음 검증 가설을 정리한다.

## Phase-End Multi-Pass Review

- [ ] 요구사항·운영·보안·지원·KPI·비용·후속 사업·문서 검토를 완료한다.
